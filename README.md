---

## El código no se publica aquí

Desde agosto de 2026, el código de este proyecto **no se aloja en GitHub**.

No es abandono ni un incidente: es una decisión, y conviene decir por qué. A lo
largo de 2026 los registros de paquetes y las plataformas de código han sufrido
ataques encadenados de cadena de suministro —Shai-Hulud, ChainDrop en agosto,
extensiones maliciosas que se llevaron miles de repositorios privados—. Alojar
aquí el código de herramientas de criptografía y de custodia de evidencia dejó
de ser una decisión neutra.

**El código se entrega a pedido**, con su firma y su suma de verificación, a
quien lo necesite para evaluarlo, auditarlo o integrarlo.
